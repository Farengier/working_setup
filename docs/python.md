## Локальное окружение для проекта
### Более современный подход - uv

uv install python <version>

### Устаревающий подход - venv

`python -m venv venv`
Вызов модуля `-m venv` создает в текущем каталоге папку venv, где будут лежать копии библиотек зависимостей проекта.

Активируем окружение
`source venv/bin/activate`

Деактивируем
`deactivate`
